em Units in css

The em unit is relative to the font size of the parent element. So, if the parent element has a font size of 16px, then 2.5em would result in 40px.

rem unit in css

The rem unit is relative to the font size of the root HTML element (). Unlike em, which is relative to the font-size of its parent element, rem always refers to the font-size of the element, regardless of its position in the document tree. This makes rem very useful for creating scalable and responsive designs. By changing the font-size of the element, all elements sized with rem units will scale proportionally throughout the entire page
